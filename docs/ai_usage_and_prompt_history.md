# AI usage and prompt history

YottaFlex allows any AI tool but asks for the full prompt history and an honest account of how AI
was used. This file is that account.

## Tools used

| Tool | Model | Used for |
|---|---|---|
| AI chat assistant | not recorded | Turning the brief and the two PDFs into a step-by-step implementation guide |
| Claude Code (desktop app) | Claude Opus 5.5 | Planning, writing code, SQL, tests and documentation; running the generator, validation and tests |

## Where AI accelerated the work
- Turning the brief and the step-by-step guide into a schema, a workflow design and a project layout.
- Writing the generator, the workflow guards, the 101 validation checks, the tests and the first drafts of every document.
- Running everything and reporting failures.

## Where I relied heavily on AI
- Most of the code and documentation in this repository was generated by Claude Code. I am not claiming I wrote it from scratch.

## Issues found during validation and fixed
- **Records dated after the snapshot.** The first version let cases open after the `as_of` date, so they showed status `open` with future timestamps. Fix: assessment due dates now end before the snapshot, and a new check (`not_after_as_of_*`) fails if any timestamp is later than `as_of`.
- **Snapshot date with no in-progress cases.** With `as_of` at the end of June, every case had finished. Moving it to 2026-05-25 gives a realistic mix (cases under review, appeals pending).
- **Analysis query parsing.** A header comment in `sql/analysis_queries.sql` contained the query-name marker and broke the parser. Comment reworded.
